# 奖惩机制设计（初版参考稿）

> 状态：讨论稿。数值为相对量级的初版建议，正式上线前需通过模拟和灰度测试调优。
> 配套概念：观点擂台 / 结论书 / 立帖为证 / 判断力战绩 / 改换阵营证词（见头脑风暴记录）。

## 一、定位与目标

本机制服务于一个核心理念：**平台要让"被检验过的判断"产生价值，而不是让"吵赢"产生价值。**

因此，体系最终要让以下四种人赢：

1. **看得准**：预测、裁定后来被现实验证的人。
2. **接得住**：正面回应挑战、让争论收敛的人。
3. **改得动**：被说服后公开认错、附证词的人。
4. **判得公**：陪审与裁定行为经得起事后复核的人。

与这四件事无关的行为，一律只给小额奖励或不给奖励。

## 二、货币体系：双层结构

**必须拆成两层，不能混成一个积分：**

### 1. 逻辑币（可花费）

- 用途：发赏金、押注（立帖为证）、陪审入场费、解锁高级功能。
- 定位：负责引流和引导行为，可以大方发放，但必须有每日/每周上限防止刷量。
- 特点：会被消耗（需要设计"币的出口"以对抗通胀，如赏金、押注）。

### 2. 战绩（不可花费）

- 定位：长期信誉，决定治理权（投票权重、陪审资格、押注上限）。
- 分类记账，互不混淆：
  - **判断力**：预测、裁定准不准（校准度）。
  - **贡献**：论点被采纳进结论书多少。
  - **诚实**：认错、改换阵营的记录。
- 特点：不可购买、不可转让、只能靠真实行为和时间积累。

## 三、奖励哪些行为

| 行为 | 逻辑币 | 战绩 | 设计意图 |
|---|---|---|---|
| 发布合规节点（支持/反对/补充） | +5（每节点一次） | 无 | 只覆盖参与成本；低门槛保住表达欲；防刷靠上限 |
| 反驳通过"复述检验"后发出 | +10 | 无 | 奖励"接得住"这个动作本身 |
| 节点被采纳进结论书（merge） | +200 | 贡献 +1 | 主奖励：论证成为产品的一部分，相当于 PR 被合并 |
| 论据被标注为"改变了某人决定/立场" | +500 | 说服 +1 | 全平台最高单项奖励；说服者与被说服者双向记账 |
| 公开改换阵营并附证词（须引用新证据） | +300 | 诚实 +1，并豁免本次声望损失 | 全网稀缺行为；认错必须划算到让人主动做 |
| 立帖为证到期判对 | 返还赌注 + 100~300（按难度/置信度） | 判断力校准 + | 让"看得准"产生复利 |
| 及时回应直接挑战且被认可 | +100 | 守擂 +1 | 收敛行为本身就该给钱 |
| 陪审裁定与终局一致 | +50 | 裁定校准 + | 判得准的人权重慢慢变大 |
| 成功上诉推翻错误结论 | +150 | 纠错 +1 | 挑战权威要有利可图 |
| 侮辱性内容主动改写后发送 | +10 | 无 | 引导优于禁止 |
| 完成理性讨论课程 | +100（一次性） | 无 | 用教育做门槛 |

**关键规则：**

- 采纳、说服、判对等高价值行为**不设每日上限**（稀缺且难伪造，值得无限奖励）。
- 发布节点、改写等低门槛行为设**每周上限**（约 300 币），断掉刷量收益。
- "被说服"双向记账：改主意的人拿诚实奖励，说服他的人拿说服战绩，两边都赢，平台上就没有人害怕被说服。

## 四、惩罚哪些行为

**惩罚哲学：**

- 小额高频行为：用代币和冷却管。
- 中等行为：用战绩记录管。
- 系统性作弊：才给予"社会性死亡"（封禁、清战绩）。
- 结构性惩罚比扣分有效：如"未回应的反驳自动挂红"——公开、持续、给论点持续减分，比扣 500 币都疼。

| 行为 | 处罚阶梯 | 结构性后果 |
|---|---|---|
| 程序违规（跑题、重复、无源事实断言） | 首次：AI 折叠 + 收回节点奖励；累计：-20/次 → 4 小时创作冷却 → 需押金才能发言 | 折叠降权；申诉成功全额返还 +10 补偿（防 AI 误判） |
| 侮辱/人身攻击 | 给改写选项：改写无罚（+10 好市民）；坚持发送：冷却 5 分钟 + 扣 50 + 帖标"情绪帖"；陪审确认的恶意攻击：折叠 + 扣 100 + 战绩记"攻击" | 攻击记录累计压低裁定权重；屡犯禁言 |
| 弃战（提出挑战后消失） | 没收挑战押金（50 币）；累计 3 次后挑战需双倍押金并显示"鸽王"标记 | 未回应的反驳自动变红——真正的惩罚是曝光 |
| 楼主无视致命反驳强行关闭 | **不即时处罚**，记录"带未决风险关闭" | 事后算账：若现实/陪审确认反驳成立 → 决策战绩扣分、结论书标记"争议关闭"；判对则加分 |
| 虚假跑题举报/恶意 flag | 前几次警告；错误率超阈值后 -10/次 + 收回 flag 权 7 天 | 无 |
| 伪更新/墙头草（无新证据反复横跳） | 不奖励；"飘忽度"上升 | 诚实战绩权重衰减，标注"随大流"而非"被说服" |
| 刷赞、小号自导自演、合谋刷战绩 | 代币清零、相关战绩冻结、权重归零、封禁 | 战绩是治理权，确证的系统性作弊必须出局 |

**"楼主强行关闭"为什么不当场罚：**

当场罚会误伤真正想清楚的人——他可能确实评估过风险、愿意承担。所以进入事后审计：关闭时系统记录"哪几条反驳未回应"，之后由现实或陪审判断他关对了没有。

**惩罚延迟到真相出现时再执行，是这个平台最特别的地方。**

## 五、防刷与校准机制

1. **期望值设计**：刷量行为的期望收益必须低于诚实行为。垃圾节点期望是"+5 但大概率被折叠收回"，认真写一条被采纳的节点是"+200"。用户嘴上不看规则，身体会按期望值行动。
2. **战绩不可购买、不可转让、绑定账号行为历史**；陪审资格、投票权重、押注上限全部跟着战绩走。
3. **近因加权**：裁定权重看最近 6~12 个月表现；历史留痕但不当免死金牌。早期封神的人后来瞎判，权重照样掉。
4. **分权执行**：AI 只自动执行低风险惩罚（折叠、冷却、扣小额代币）；所有扣战绩的处罚必须走人审或陪审，AI 只能提交建议。
5. **规则透明、奖惩记录可查**：每个用户能看到自己的完整账本（哪条被采纳、哪次判错、哪次认错），也能看到规则全文。

## 六、闭环示例（钱怎么流动）

小明发根节点"我要不要裸辞开民宿"（+5）。

老张是民宿老板，挂了一条反对节点，附真实经营数据，通过复述检验（+10）。小明 7 天没回应，这条反驳自动变红、悬而未决。

李四立帖为证押 100 币赌"小明会后悔"，难度系数 2（赌注风险 +200）。

小明回来认真看完老张的节点，决定改为"先试住一个月再决定"：

- 小明附证词认错：+300 币、诚实 +1；
- 小明采纳老张的节点进结论书：老张 +200、贡献 +1；
- 因为该论据改变了小明的决定，老张再拿说服奖励 +500。

三个月后现实揭晓：小明没后悔。李四押错，损失 100 币赌注；但他写了诚实证词"我赌错了，是我低估了试住的价值"，拿到诚实奖励，判断力记录的损失被部分豁免。

**留下的不是一地鸡毛，而是一份带采纳链路的结论书、两条被验证的判断记录、一次公开认错。**

## 七、分阶段落地建议（MVP 子集）

初期不需要整套体系，建议按以下顺序分期上线：

**第一期（MVP，只做结构性激励，不做代币经济）：**

- 反驳必须挂在具体断言下，"未回应"自动变红、悬而未决——结构性惩罚先行。
- 结论书采纳标记（merge）与采纳者署名——让贡献有落点。
- 立场时间线 + 改换阵营证词（附证词才能算诚实记录）。
- 立帖为证到期揭晓，输赢自动记账。

**第二期（引入轻量代币）：**

- 采纳 +200、说服 +500、诚实 +300 等核心大额奖励。
- 挑战押金、弃战没收、鸽王标记。
- 每周微行为上限。

**第三期（治理体系）：**

- 陪审团、战绩权重、裁定校准记录。
- 申诉通道与 AI 误判补偿。
- 完整防刷（水军检测、飘忽度、恶意 flag 阶梯）。

## 八、开放问题

1. **逻辑币是否可兑换真钱？**
   建议初期绝不：一碰真钱，刷子、羊毛党、法律风险全来。等"帮助用户做出正确决策"的采纳体系跑稳后，可允许楼主用真钱发赏金（"谁能给我一条改变决定的论据"），那才是价值兑现的时刻。
2. **惩罚是否公开展示（如"鸽王"徽章）？**
   展示增强威慑，但羞辱过度会杀死认错文化，边界需要单独讨论。
3. **数值校准**：奖励配比（如采纳与说服的比例）、惩罚阶梯的触发阈值，需要小流量灰度 + 模拟验证。
