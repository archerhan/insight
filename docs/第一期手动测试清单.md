  2. A 在结论书向导漏勾风险时无法发布，逐条勾选后带险发布；
  3. 话题状态为带险关闭，结论书展示未决风险区；
  4. B 查看结论书 / Markdown 能读到风险说明。

- [x] **E2E-04 立帖为证揭晓闭环**：
  1. A 发布开启立帖为证的话题并收敛出结论书；
  2. B 与 C 各押一个方向；
  3. 到期后 A 回访选择「没有后悔」；
  4. B / C 收到揭晓结果通知，我的押注、判断力、通知与话题页结果全部一致。

- [x] **E2E-05 公共议题（claim）边界**：A 发起 claim 话题，B 反驳并击穿根立场后击杀链自动提升；确认楼主无关闭入口、无立帖为证登记、无回访揭晓入口，话题保持进行中。

## 13. 权限、并发与一致性（负向 / 健壮性）

- [~] **SEC-01** 未登录直接提交（发布 / 支持 / 反驳 / 回应 / 结论书 / 立场变更 / 押注 / 回访）：均被重定向到登录页或给出明确登录提示，不产生脏数据。
- [x] **SEC-02** 登录但未完成须知直接提交：被重定向到须知页，不落库。
- [x] **SEC-03** 话题已收敛 / 带险关闭后：所有新增论点、反驳、回应入口不再有效（见 ARENA-16）。
- [x] **SEC-04** 权限矩阵抽查：只有楼主可出结论书与回访；只有目标作者可回应 / 承认击穿；只有论点作者可修订 / 迁移；楼主不能押自己；同话题立场变更一次。
- [x] **SEC-05** 重复提交防抖：快速双击发布 / 提交按钮，只产生一条话题 / 论点 / 反驳 / 押注（刷新后验证）。
- [~] **SEC-06** 公开读安全：未登录用户可浏览广场与话题全部公开内容，但不看到任何个人战绩、通知、操作表单。
- [x] **SEC-07** 页面刷新后状态一致：焦点、tab、红条、计数、通知角标不出现前后不一致。
- [x] **SEC-08** 内容不可物理删除：话题页 / 论点卡无删除按钮；被击穿 / 悬空 / moot 内容仍以归档态可见，而不是消失。
