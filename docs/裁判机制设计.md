# 裁判机制设计（可落地版）

> 状态：设计稿。数值与门槛为初版默认值，上线前需灰度调优。
> 配套文档：《奖惩机制设计.md》（货币、战绩、奖励惩罚表）、《视觉呈现设计.md》（界面与视觉规范）。
> 配套概念：观点擂台 / 树状论点 / 结论书 / 立帖为证 / 改换阵营证词。

## 一、设计总纲

裁判机制要回答的唯一问题是：**树的每一个状态变化，凭什么发生、由谁决定、错了怎么纠正。**

### 四条铁律

1. **分权**：没有任何一方拥有完整裁判权。AI 管程序，楼主管个人决策，众人管质量，时间管终审。
2. **分级**：判定按"判错代价"分级。低风险快速自动，高风险高门槛人工；争议越大，门槛越高。
3. **留痕可申诉**：一切裁定写入审计账本（谁、依据、权重、结果），全部可申诉，除系统性作弊外全部可逆。
4. **AI 只有建议权，没有裁决权**：AI 可以执行纯程序性、可逆的小动作，但任何影响论点生死、用户战绩的裁定必须有人参与。

### 三种裁判的本质分工

| 裁判 | 角色 | 管什么 | 不管什么 |
|---|---|---|---|
| AI | 程序裁判 | 挂载、重复、复述检验、来源完整性、侮辱识别 | 论点真伪、跑题定性、是否折叠 |
| 人（楼主/众人/陪审） | 质量裁判 | 跑题、论点是否站得住、采纳、关闭、惩罚 | 预判未来（交给时间） |
| 时间/现实 | 终局裁判 | 预测揭晓、决策回访、事件反转 | 无法即时介入的日常琐事 |

## 二、裁决清单与裁判权分配

| 裁决类型 | 判定问题 | 默认裁判 | 升级路径 | 错误成本 | 可逆性 |
|---|---|---|---|---|---|
| 程序检查 | 挂载是否正确、是否重复、反驳是否通过复述检验、事实断言是否有来源 | AI 自动（仅标记/提示） | 作者申诉 → 轻陪审 | 低 | 高 |
| 相关性 | 节点是否回应了父断言的"跑题" | AI 建议 + 用户 flag | 达阈值自动软折叠 → 申诉 → 轻陪审 | 中 | 高（折叠不删除） |
| 有效性 | 反驳是否"击中"、论点是否被击穿 | 作者回应 + 观众校准票 | 争议 → 轻陪审 / 重陪审 | 中高 | 中（可上诉/修订） |
| 采纳 | 节点是否进入结论书（merge） | 个人决策：楼主；公共主张：关闭时的陪审 | 作者不可自采纳 | 低 | 中（可追加修订） |
| 关闭/收敛 | 话题是否可以出结论书 | 个人决策：楼主；公共主张：收敛公示 + 无人反对 | 有人反对 → 重陪审 | 高 | 中（结论书版本化） |
| 惩罚 | 扣战绩、禁言、封禁 | 陪审（AI 只能建议） | 上诉陪审 | 高 | 低（申诉可翻案） |
| 终局 | 预测应验/破产、决策后悔与否、事件反转 | 时间自动 / 到期揭晓 | 结果争议 → 事实复核轻陪审 | 最高 | 不可逆（但可标注争议） |

## 三、节点状态机（树如何被裁定改变）

每个节点在任何时刻只有一个状态。**状态迁移必须携带一条裁定记录。**

| 状态 | 含义 | 进入条件 | 视觉 |
|---|---|---|---|
| pending | 待程序检查 | 新节点发布 | 半透明 |
| active | 正常参与 | AI 程序检查通过 | 默认 |
| challenged | 被挂红：有未回应的直接反驳 | 反驳节点挂上，作者未回应 | 红点/红边 |
| disputed | 争议仲裁中 | flag 达阈值或有人提请仲裁 | 黄色 |
| responded | 已回应挑战 | 作者对反驳给出有效回应 | 恢复默认 |
| refuted | 被击穿/不成立 | 反驳被作者承认或被陪审确认击中 | 灰色 + 删除线可选 |
| 悬空（orphaned） | 支撑链断裂：父论点已失效，其"支撑型"子孙失去论证目标；论据本身未必为假 | 父论点被击穿后，沿支撑边自动标记 | 淡显 + 虚线框，可抢救 |
| moot（目标已移除） | 指向已失效论点的"反驳型"后代：目标没了，不判胜负 | 父论点被击穿后自动标记 | 归档展示，不参与计分 |
| merged | 被采纳进结论书 | 楼主/陪审采纳 | 紫色高亮 |
| collapsed | 被折叠（软删除） | 跑题/重复/违规经确认 | 淡显，可展开 |
| closed_with_risk | 带未决风险关闭 | 楼主在存在红反驳时强行出结论书 | 橙色标记 |
| superseded | 已被新版本取代 | 作者修订观点，旧版存档 | 归档样式 |
| adjudicated | 已被现实终审 | 预测到期揭晓/回访完成 | 带"应验/破产/后悔"徽章 |

### 关键迁移规则

- **反驳挂上即 challenged**：不需要任何人投票。这是结构性压力，比人工干预快。
- **未回应计时**：3 天变橙色提醒；7 天持续红色，父论点在结论书中自动降权展示；14 天且作者活跃仍不回应，可发起"默认判负"请求 → 轻陪审确认。
- **折叠 ≠ 删除**：折叠内容保留可展开、可申诉；只有系统性作弊才永久清除。
- **修订优先于判负**：论点被击穿后，作者可以选择"修订原观点"生成新版本，旧版标记 superseded，反驳指向旧版继续有效。鼓励认错和修正，而不是打死。
- **击穿不向下传染**：击穿只作用于被击穿节点本身（它作为论据的有效性失效，不等于命题为假）。
  - 沿"支撑边"向下的子孙 → 自动标记**悬空**：论证目标已死，论据可能仍然为真；
  - 沿"反驳边"向下的后代 → 自动标记 **moot**：目标已移除，不判胜负、不惩罚（成功"击杀"的那条链单独表彰）；
  - 事实层不连坐：只有被单独证伪、且断言同一事实的节点才联动。
- **支撑子节点被击穿只削弱父论点，不自动击穿**：少一根柱子不等于楼塌；父论点可能还有别的支撑，仍可继续存活。
- **悬空节点的三种出路**：① 作者修订出新版父论点后，"抢救迁移"仍有效的子孙（需通过相关性检查）；② 证明与议题直接相关且独立成立 → 走"提升"通道进入理由层；③ 保持悬空只读，留痕备查。

## 四、裁判升级阶梯（核心流程）

从最轻到最重共五级，外加终审。**能低级别解决的不升高级别，高级别只处理高争议。**

| 级别 | 裁判 | 人数/门槛 | 时限 | 通过条件 | 适用 |
|---|---|---|---|---|---|
| L0 | AI 自动 | — | 秒级 | 规则命中 | 挂载/重复/复述/来源缺失的标记与提示 |
| L1 | 作者/楼主单方 | 1 人 | 即时 | 本人操作 | 采纳节点、个人决策关闭、修订观点 |
| L2 | 轻陪审 | 3 人 | 48 小时 | 简单多数（按权重） | 跑题争议、默认判负、AI 判定申诉、事实复核 |
| L3 | 重陪审 | 5 人 | 72 小时 | ≥3 票且权重占比 ≥60% | 折叠确认、公共主张关闭、扣战绩级惩罚 |
| L4 | 上诉陪审 | 7 人 | 5 天 | ≥5 票且权重占比 ≥70% | 推翻 L2/L3 裁定（需申诉押金） |
| L5 | 时间/现实 | 自动 | 按到期日 | 事实结果 | 预测揭晓、决策回访、事件反转 |

### 各级触发方式

- **L0**：节点发布即触发；命中后只"提示作者修改"或"标记待完善"，不直接处罚。纯客观重复可自动软折叠，但给作者 24 小时申诉窗口。
- **L1**：楼主采纳、关闭、修订，操作即时生效并留痕。
- **L2**：以下任一条件触发——① 跑题 flag 达 3 个独立用户；② 作者对 AI 标记申诉；③ "默认判负"请求；④ 预测结果争议。
- **L3**：以下任一条件触发——① L2 裁定结果被争议（自动升 L3 复审）；② 折叠动议（重复违规）；③ 公共主张关闭动议遭反对；④ 任何扣战绩惩罚提议。
- **L4**：对 L2/L3 结果不服，付 100 币申诉押金（防滥用）。胜诉退押金 +100 补偿，误判计入原裁判的校准记录。
- **L5**：立帖为证到期日自动揭晓；楼主决策关闭后 T+30/90/180 天收到回访提示，可自愿回答"后悔了吗、哪条论据最值钱"。

## 五、关键流程与规则走查

### 1. 跑题判定（争议度最高的日常问题）

跑题的定义固定在局部：**节点有没有回应父节点的断言**，不评判它是否服务于根话题。

1. 发布节点时强制声明关系类型（支持/反对/补充/质疑/澄清）。
2. AI 预筛给出"疑似跑题"建议（仅供参考，不执行）。
3. 任何完成课程的用户可 flag，每人每天 5 次配额；正确率高则配额增加，错误率超阈值则收回 flag 权（见奖惩文档）。
4. 24 小时内 3 个独立用户 flag → 节点软折叠（可展开、可申诉），进入 7 天观察期。
5. 观察期内无申诉 → 正式折叠；有申诉 → 自动开 L2 轻陪审。
6. 铁律：**根作者不能用"跑题"保护自己的观点**——他想压制致命反驳，只能走"带未决风险关闭"，性质不同、记录不同。

### 2. 反驳"击中"判定（决定树深度的关键）

1. 反驳节点挂上父断言 → 父节点进入 challenged，计时开始。
2. 父作者有三种回应：
   - **认领并回应**：给出有效反驳 → 节点回 responded；反驳人若不服可申请 L2。
   - **承认击中**：父节点变 refuted；作者可再选择修订观点（生成新版本，旧版 superseded）。
   - **不回应**：3 天橙、7 天红（结论书降权展示）；14 天后可被申请"默认判负"→ L2 确认。
3. "击中"的判定标准（陪审指引）：反驳是否直接针对父断言的论证结构（前提错误、推理断裂、事实证伪、结论不必然），而不是态度或立场。
4. 被击穿不等于人格失败：refuted 节点保留全部讨论链，作者若修订得当，反而获得贡献记录。

### 3. 采纳与关闭（产出结论书）

**个人决策话题**（"我要不要……"）：

- 楼主可以随时采纳节点（merge）或出结论书（close）。
- 若存在未回应的红反驳，系统弹窗逐条列出，楼主必须勾选"我已知晓并接受风险"才能关闭 → 状态 closed_with_risk，计入决策战绩，留待时间审计。
- 楼主关闭后不可再改口删帖，但可以发"修订版结论书"（版本化）。

**公共主张话题**（"X 是否成立"）：

- 楼主没有关闭权。关闭由收敛机制触发：AI 检测创新度衰减（新贡献连续为重复论点）+ 3 位高战绩用户提议 → 进入 7 天"关闭公示窗口"。
- 窗口期内：无新证据且无人反对 → 自动进入"暂定成立"，陪审把有效分支批量标为 merged 写入结论书。
- 窗口期内有人反对 → 开 L3 重陪审决定是否关闭。
- 任何人可用"新证据"重新打开已关闭话题（需通过创新性检查，见奖惩文档）。

**采纳资格（谁能进结论书正文）**：

- 写入结论书正文的"采纳"默认只限**理由层**——即议题的直属子论点。深层论证是"为什么这条理由成立"的支撑，应作为脚注而非正文。
- 深层论据进入结论书有三条路径：
  1. **支撑链脚注**：理由层节点被采纳时，附带其关键支撑链与沿途贡献者署名，一并收入结论书；
  2. **击穿记录**：深层反驳击穿中间层后，作用体现为上层状态变更，击杀者获得说服战绩；
  3. **提升通道**：深层论点若与议题直接相关且独立成立（不依赖已失效祖先），可申请提升为理由层，由陪审确认。
- 区分两种"采纳"：**楼主被某深层论据说服**（任意深度都可，记为改换阵营证词）与**写入结论书正文**（限理由层），二者不能混为一谈。

### 4. 惩罚裁定（扣战绩必须走人）

1. AI 发现违规只提交"建议 + 证据包"（原文、命中规则、置信度）。
2. 扣代币级小惩罚：AI 按阶梯自动执行（可申诉，误判补偿）。
3. 扣战绩、禁言、封禁：必须开 L3 陪审；投票用权重制。
4. 陪审表决采取"计票公开、个人票保密"：对外只显示汇总，系统内部记录每人投票供校准，防止报复和跟票。
5. 确证的水军/自导自演（多账号关联、合谋刷战绩）走 L4，处罚不可申诉仅可复核（保留极端通道）。

### 5. 结论书导出（导出物定义）

导出物 = **一份不依赖平台也能独立阅读的"当前决策快照"**。正文只含结论，证据链以脚注形式存在。

包含内容：

- **头部**：议题、状态（已收敛·暂定 / 争议中 / 带险关闭）、版本号、导出时间。
- **结论**：结论本身 + 建议行动 + 适用前提（如"前提：存款可支撑 6 个月"）。
- **采纳理由（理由层）**：每条含论点原文、作者与战绩、状态徽章、关键支撑链摘要（脚注）、引用来源链接。
- **未决风险**：红反驳清单，注明影响哪条理由、挂起多久——让读者知道"这份结论哪里还不可信"。
- **裁决与修订记录**：v1→vN 变更摘要、击穿/采纳事件时间线简表。
- **元信息与验证**：参与者统计、立帖为证揭晓日、已受现实检验的标记。
- **回溯保障**：脚注带节点 ID / 话题链接；正式导出物带内容指纹（哈希），防篡改冒充。

明确**不导出**：整棵树（属论证地图的职责）、被折叠的跑题内容、情绪帖。

两种模式：

- **简要版**：结论 + 采纳理由 + 未决风险，适合群聊与社交传播。
- **完整版**：追加裁决记录、修订历史、完整支撑链，适合存档与审计。

格式：Markdown（可编辑）、PDF（正式分享）、摘要图卡（传播）。

## 六、陪审员资格、抽取与权重

### 资格门槛

- 注册 ≥14 天、完成理性讨论课程。
- 近 30 天有 ≥3 次有效裁定记录，或 ≥10 次有效互动（MVP 期可放宽到活跃用户）。
- 战绩非负（有未结清惩罚记录者不可当陪审）。

### 抽取规则

- 从合格池随机抽取，同一用户相邻两案不重复中签（防小圈子）。
- 48 小时内未响应视为缺席，自动补抽；连续缺席 3 次暂停陪审资格 30 天。
- 仲裁期间，争议节点及其子节点冻结状态变更，防止边裁边打。

### 权重公式（正式版）

```
权重 W = 1
       + 校准加成：min(3, max(-0.5, (近30次裁定一致率 - 0.5) × 6))
       + 贡献加成：min(2, 采纳进结论书次数 × 0.1)
```

权重范围约 0.5 ~ 6。MVP 阶段可退化为等级制：普通 1 / 白银 2 / 黄金 3，等级由近 30 次一致率决定。

### 陪审报酬与押金

- 中签并完成投票：+50 币（小额，防刷靠随机抽取）。
- 与终局/上诉结果一致：额外计入裁定校准战绩。
- 恶意搅局（明显无理由投反对拖延仲裁）：按虚假 flag 阶梯处理。

## 七、裁判的裁判（校准系统）

这是整套机制的自净核心：**每个裁判（含 AI）自己都在被记录和打分。**

1. 每条裁定事后有三个打分来源：
   - **终局**：预测被现实揭晓时，相关裁定对错自动结算。
   - **上诉**：裁定被 L4 推翻 = 一次误判记录。
   - **抽样复核**：系统随机抽样已结裁定，由更高战绩用户匿名复核（不改变结果，只记账）。
2. 校准记录采用近因滑动窗口（最近 30~50 次），旧记录留痕但权重只看近期。
3. 权重低到阈值 → 自动失去陪审资格；多次误判 → 降级；恶意误判 → 按惩罚流程处理。
4. **AI 同样被监控**：记录 AI 判定的申诉率和被推翻率；指标恶化 → 自动降级为纯建议模式，触发人工调参。

## 八、防作弊与防合谋

- **随机黑箱抽取**：陪审抽取算法不公开细节，事后审计可验证。
- **投票期间隔离**：仲裁期内，陪审员在争议节点下的互动不产生任何收益记录，防"边裁边赚"。
- **马甲检测**：多账号共享设备/行为特征 → 贡献与战绩合并计算；确证刷子走 L4。
- **权重稀释**：公共主张的关闭与采纳要求权重占比达标（≥60%），少数高权重用户无法独断，多数低权重用户也无法淹没。
- **一切留痕**：审计账本对用户公开本人记录，对治理层公开全量记录。

## 九、落地分期

### P1（MVP：先让树自己长出秩序，不做完整陪审）

- L0 AI 程序检查：只标记、提示、软折叠（带 24 小时申诉窗口）。
- 反驳挂上即挂红 + 未回应计时（3/7/14 天自动状态流转）——**结构性裁判先行**。
- 父论点被击穿时自动批量标记：支撑型子孙 → 悬空，反驳型后代 → moot（纯自动、可申诉）。
- 楼主采纳与关闭（个人决策），带"未决风险"弹窗审计。
- 跑题 flag：3 个独立 flag 自动软折叠，申诉先走人工复核（MVP 用编辑/种子用户充当，后续替换为陪审）。
- 公共主张关闭：收敛公示 7 天 + 无异议自动暂定成立。

### P2（引入陪审与校准）

- L2/L3 陪审上线，权重等级制起步。
- 申诉通道与押金；折叠、默认判负、惩罚裁定全部迁移到陪审。
- 校准记录上线：裁定一致率开始影响权重。

### P3（时间终审与防合谋）

- 立帖为证自动揭晓、决策回访（T+30/90/180）、事件反转修订。
- AI 判定质量监控与自动降级。
- 连续权重公式、防合谋检测、抽样复核。

## 十、开放问题

1. **身份匿名度**：建议"假名 + 长期历史战绩"（可换名不换战绩），既降低报复风险，又让战绩可追踪。真名实名会抑制认错，完全匿名会让战绩失效。
2. **裁判池冷启动**：新话题、新社区陪审员不足时，P1 用编辑/种子用户兜底，但兜底期间的所有裁定同样留痕、事后可被陪审翻案。
3. **误判的补偿标准**：AI 或陪审误判导致用户损失（曝光、奖励），补偿金额与恢复原状的具体规则，需要随真实数据定。
4. **"默认判负"是否过重**：14 天未回应判负对活跃用户公平，但低频用户可能只是没看到——是否需要"回归提醒"（站内信+邮件）后再计时？
