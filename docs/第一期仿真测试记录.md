## 五、问题清单与修复

### ISSUE-001 复述校验前后不一致

- 现象：本地启发式复述检验通过后，服务端 LLM 校验仍可能拒绝，页面同时显示「复述检验通过」和红色错误提示，用户无法判断当前是否真的可以提交。
- 证据：[issue-001-paraphrase-server-reject.png](./test-evidence/issue-001-paraphrase-server-reject.png)
- 修复：`TopicActionState` 增加 `failedCheck`，服务端判定失败于 `paraphrase` 时，表单自动切回复述步骤并展示服务端原因；本地和服务端口径不再同时显示互相矛盾的状态。
- 代码：`src/app/topics/[id]/actions.ts`、`src/components/arena/arena-composer.tsx`

### ISSUE-002 「全部标为已读」后顶栏角标不刷新

- 现象：通知列表已清空未读、按钮消失，但顶栏铃铛仍显示旧未读数，直到用户再导航 / 刷新。
- 修复：标记已读后刷新根布局缓存，使顶栏未读数与通知列表同步。
- 代码：`src/app/notifications/actions.ts`、`src/app/notifications/actions.test.ts`

### ISSUE-003 向导「下一步」可能被误判为发布

- 现象：自动化连续操作时，第二步点「下一步」会立即进入第三步并触发「发布中…」，未给用户确认第三步规则的机会；已产生一条 `QA-仿真测试：无意识发布复现（可删除）` 辅助数据。
- 证据：[issue-003-next-click-publishes.png](./test-evidence/issue-003-next-click-publishes.png)
- 修复：进入第三步后的 400ms 内不接受表单提交，防止同一次指针序列被重定向到「发布话题」按钮；正常用户看完预览再点发布不受影响。
- 代码：`src/app/topics/new/topic-wizard.tsx`

### ISSUE-004 程序检查耗时长但按钮无反馈

- 现象：开启 LLM 增强时，提交反驳 / 回应 / 结论书 / 押注等操作可能等待十秒以上；原按钮没有 pending 文案，用户容易重复点击。
- 修复：对线、回应、修订、抢救迁移、结论书、立场变更、押注、回访表单补充「提交中…」文案与禁用态。
- 代码：`src/components/arena/*`、`src/components/conclusion/*`、`src/components/predictions/*`

### ISSUE-005 非法话题 ID 返回 500

- 现象：访问 `/topics/not-a-uuid` 时，页面并行读取对线 / 结论书数据，未校验 UUID，导致数据库查询报错并返回 500。
- 修复：话题页在读服务前先用统一 UUID 形状校验拦截非法 ID，直接按 404 处理。
- 代码：`src/db/services/topics.ts`、`src/app/topics/[id]/page.tsx`、`src/app/topics/[id]/page.test.tsx`

### ISSUE-006 非法 tab 回退时未加载默认视图数据

- 现象：`?tab=foo` 会回退到默认视图，但数据加载分支仍按“显式指定了非法 tab”处理，导致已收敛话题显示「结论书暂不可用」。
- 修复：非法 tab 先归一为“未指定 tab”，再按状态加载默认视图数据。
- 代码：`src/app/topics/[id]/page.tsx`、`src/app/topics/[id]/page.test.tsx`

### 未修复 / 待用户处理

- Vercel Production 的 GitHub OAuth 仍是 `Configuration` 错误，见 BLOCK-02。
- 挂红 3 / 7 / 14 天阶段流转未做完整时间推进验证，见 BLOCK-03。
- `QA-仿真测试：无意识发布复现（可删除）` 是复现用辅助数据，确认后可以清理。
